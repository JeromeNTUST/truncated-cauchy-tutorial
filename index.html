金融數學專題
Truncated Cauchy Model

對象：具備微積分基礎之大學生

為什麼我們需要「截斷」柯西分布？

在財務工程中，標準常態分布往往無法捕捉金融市場「黑天鵝」事件（即極端報酬率，厚尾現象）。柯西分布 (Cauchy Distribution) 擁有完美的「厚尾」，但它有一個致命缺點：它的變異數與平均值在微積分上是發散的（算不出來）！

本節學習地圖

這份手稿的第二節展示了數學家如何解決這個問題：將柯西分布在正負 $B$ 的地方「切掉」（截斷）。
我們將沿著以下路線學習：
1. 建立基礎：對稱截斷 (TC)
2. 升級裝備：非對稱截斷 (ATC)，符合市場跌快漲慢的特性。
3. 解開謎題：如何利用給定的市場數據（均值、變異數、偏度、峰度）反推模型的未知參數。
4. 落地應用：將數學邏輯轉化為演算法。

一、打造基礎：對稱截斷 Cauchy 分布 (TC)

Definition 1 (對稱截斷 Cauchy 分布)

給定 $\theta > 0, B > 0$，隨機變數 $X \sim TC(\theta, B)$ 的機率密度函數 (PDF) 定義為：

$$f_{TC}(x;\theta,B)=\frac{1}{D\theta\left[1+(\frac{x}{\theta})^{2}\right]}1_{[-B,B]}(x)$$

其中常數 $D = 2 \arctan(B/\theta)$ 是為了確保總機率為 1 的正規化常數。

白話說明： 把原本無限延伸的 Cauchy 分布，在正負 B 的地方「切掉」（指示函數 $1_{[-B,B]}$）。這樣既保留了中間尖峰厚尾的形狀，又能保證期望值積分不會發散。
微積分視角 (Calculus Insight)： 為什麼 $D = 2 \arctan(B/\theta)$？
令 $z = x/\theta, dx = \theta dz$。積分 $\int_{-B}^{B} \frac{1}{1+(x/\theta)^2} dx = \theta \int_{-B/\theta}^{B/\theta} \frac{1}{1+z^2} dz$。 回憶微積分：$\int \frac{1}{1+z^2} dz = \arctan(z)$。
代入上下限，剛好是 $\theta [\arctan(B/\theta) - \arctan(-B/\theta)] = 2\theta\arctan(B/\theta)$。
Proposition 2 & Corollary 3 (動差與統計特徵)

因為 PDF 是一個對稱的偶函數 (Even Function)，所以：

  • 奇數階動差為 0： 期望值 $\mathbb{E}[X] = 0$，偏度 (Skewness) $= 0$。
  • 偶數階動差： 可使用超幾何函數 $_2F_1$ 求解。

若定義相對形狀參數 $b = B/\theta$，變異數與峰度為：

$$Var(X) = \theta^2 \left(\frac{b}{\arctan(b)} - 1\right)$$ $$Kurt(X) = \frac{\arctan(b)[b^3 - 3b + 3\arctan(b)]}{3[b - \arctan(b)]^2}$$
Proposition 4 (可行峰度與參數唯一性)

當給定目標變異數 $\sigma^2$ 與目標峰度 $\kappa$ 時，只要 $\kappa > 9/5$，就必然存在且唯一一組參數 $(\theta, B)$。

白話說明： 這是給實務界的定心丸！它證明只要市場數據算出來的峰度大於 1.8，你就一定能找到唯一對應的參數。

二、升級裝備：非對稱截斷 (ATC)

金融市場跌得快、漲得慢（存在負偏度）。對稱模型不夠用，所以要把模型拆開重組，變成非對稱的版本。

Def 5: 單邊積木 (HTC)

把對稱分布剖半，只拿大於零的那一半：

$$f_{HTC}(x) = \frac{1_{[0,B]}(x)}{\theta\arctan(b)[1+(x/\theta)^2]}$$
Prop 6: HTC的動差

利用微積分求出各階動差（備用）：

$$h_n(\theta, B) \equiv \mathbb{E}[\xi^n] = \theta^n c_n(b)$$
Definition 7 (核心：非對稱截斷 Cauchy 分布 ATC)

我們用機率 $p$ 把「正向跳躍」和「負向跳躍」拼起來：

$$ X \triangleq \begin{cases} \xi^+, & \text{with probability } p, \\ -\xi^-, & \text{with probability } 1-p; \end{cases} $$

其中 $\xi^+ \sim HTC(\theta^+, B^+)$，$\xi^- \sim HTC(\theta^-, B^-)$。

白話說明： 正向和負向的大小（$\theta$）、極限邊界（$B$）都可以不一樣，完美模擬市場的不對稱性。
Corollary 8 (ATC的動差)

將正負兩邊的動差加權平均，第 $n$ 階原始動差為：

$$M_n = p \cdot h_n(\theta^+, B^+) + (1-p)(-1)^n h_n(\theta^-, B^-)$$

（進而可推導出均值、變異數、偏度與峰度的公式）

三、解開謎題：如何用市場數據反推參數？

數學難題：維度不匹配

ATC 模型有 5 個未知參數 ($p, \theta^+, \theta^-, B^+, B^-$)，但市場通常只給 4 個目標數字（均值、變異數、偏度、峰度）。這就像有5個變數卻只有4條方程式，無法解出唯一解。

作者的解法（降維打擊）： 規定正負兩邊要「等形狀」，即 $\frac{B^+}{\theta^+} = \frac{B^-}{\theta^-} = b$。把變數降回 4 個！

Lemma 10 (還原二點分量)

假設我們已經猜到形狀參數 $b$ 是多少，利用前三個目標（均值、變異數、偏度），構造二次方程式：

$$V(b) = q_2(b) - q_1(b)^2$$ $$S(b) = \frac{q_3(b) - q_1(b)q_2(b)}{V(b)}$$ $$P(b) = \frac{q_1(b)q_3(b) - q_2(b)^2}{V(b)}$$

白話說明：這步能瞬間把正負跳躍的大小 ($\theta^+, \theta^-$) 和發生機率 ($p$) 全算出來！

Prop 11 (精確可行性)

最後一步，拿第4個目標「峰度」來比對：

$$\mathcal{K}_m(\eta; b^*) = \kappa$$

白話說明：透過電腦尋找，找出讓模型峰度剛好等於市場峰度 $\kappa$ 的那個唯一的 $b^*$。找到了，全部參數就解開了。

Corollary 12 & 13 (防呆機制與特例)
  • 實務防呆 (Cor 12)： 當平均值固定後，偏度是有極限的。程式可以先檢查輸入數據，避免陷入無解死胡同。
  • 完美對稱 (Cor 13)： 若平均值為 0，偏度不受限，且偏度對峰度的影響會變成優美的二次曲線。

四、落地應用：演算法實作 (Algorithm 1)

這就是實務上的「電腦計算操作手冊」。它將前面的微積分與代數邏輯化為程式步驟：

1 // 步驟一：防呆檢查 (Cor 12)
2 Check if targets $(\mu, \sigma, \eta, \kappa)$ are valid. If not, STOP.
3 // 步驟二：撒網尋根 (Prop 11)
4 for each trial value of $b$ do
5 Compute 2-point component moments $V(b), S(b), P(b)$
6 Evaluate error function: $f(b) = \mathcal{K}_m(\eta; b) - \kappa$
7 end for
8 Find root $b^*$ where $f(b^*) = 0$
9 // 步驟三：全面解碼 (Lemma 10)
10 Recover $p, \theta^+, \theta^-, B^+, B^-$ using $b^*$
11 // 步驟四：品管驗收
12 Recompute statistics from recovered parameters to ensure accuracy.
